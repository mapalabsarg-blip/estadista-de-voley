# El Estadista del Voley

PWA de estadisticas para voley amateur. Para usar en vivo, desde el celular.

## Features

- Registro en vivo con 2 toques
- Marcador automatico y manual
- Estadisticas por jugador y por set
- Export/import JSON y CSV
- Multiples partidos
- PWA offline instalable

## Correr local

    python3 -m http.server 8080

## Tests

    npm test
